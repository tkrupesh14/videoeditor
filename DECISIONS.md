- 2026-11-13: **:core:ai uses the official Anthropic Java SDK** (`com.anthropic:anthropic-java`, MIT) from Kotlin, per Anthropic's guidance to use the official SDK where one exists. Tests point its base URL at a local mock server, so no real credits are spent. Raw ktor HTTP was rejected.
- 2026-11-13: **Default AI model `claude-opus-5-5`** (from the claude-api reference, cached 2026-11-03: Opus 5.5 $4/$20 per MTok; Sonnet 5.5 $2/$10; Haiku 5.5 $0.10/$0.50; Fable 5.2 $8/$40). The model is user-configurable in Settings, with a picker for cheaper models since this is the user's own spend. Opus 5.5 constraints: `tool_choice` any/tool returns 400, so the code uses `auto` with `strict: true` tools. Thinking can't be disabled; effort is set explicitly (`medium`). No prefill.
- 2026-11-13: **MCP architecture** (security.md): the app hosts an authenticated bridge on an abstract Unix socket with a peer-UID check, reached by `adb forward` (no IP listener on the phone). `vedit-mcp` (`:core:mcp`) is a stdio MCP server, run on a laptop or on a VM via `ssh -R`. Pairing uses an 8-digit code plus an on-phone Allow, then a 256-bit token and HMAC challenge-response. Offline mode (`--project file.json`) edits a JSON file directly and needs no token, because nothing listens.
- 2026-11-13: **Claude app custom connectors are not supported in v1.** They require a public HTTPS endpoint with OAuth; offering authless would be unauthenticated remote control of the phone. The README documents this and the path forward.
- 2026-11-13: **API keys starting `sk-ant-oat` (subscription OAuth tokens) are rejected by format check**, enforcing the no-subscription constraint in code.
- 2026-11-13: **Timeline design accepted** (timeline.md): Long µs, half-open ranges, floor on timeline→source; strict commands (reject, never push); pure `CommandExecutor`; snapshot undo in `EditorSession` (limit 100); drags as transactions, AI suggestions as `EditPreview` committed with a revision check; IDs from a counter stored in the project. **Override:** generated schemas add `additionalProperties: false` on objects, because Claude `strict: true` tools require it (the doc had omitted it).
